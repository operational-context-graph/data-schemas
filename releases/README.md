# Releases

This directory holds one subdirectory per schema version, named `<MAJOR.MINOR.PATCH>`.

Each release subdirectory holds the release manifest for that version. The release manifest selects one revision of every
logical artifact in the release. It also records dependencies and a human-readable change log.

## Status

The release manifest format and the tooling that produces a manifest are defined and implemented separately. This
directory holds no releases yet.
