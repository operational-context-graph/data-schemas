# Schemas

This directory holds the JSON Schemas that validate the repository's own artifacts. These are committed artifacts of the
repository.

| File | Validates |
| --- | --- |
| `source-mapping-descriptor.schema.json` | Source mapping descriptor files. |
| `ocg-dsl.schema.json` | `ocg-dsl` transformation program files. |

## Status

These JSON Schemas are not authored yet. This directory holds their reserved place. The `ocg-dsl` schema defines the
structure of a transformation program. The set of allowed functions in the language is defined separately and is kept in
sync with the schema.
